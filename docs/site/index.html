Sistema de Gestion de Citas Medicas

Proyecto academico - Curso Herramientas de Desarrollo

Descripcion

Sistema web para la gestion de citas de un consultorio/clinica, que permite administrar pacientes, medicos, especialidades y la agenda de citas medicas. Desarrollado con Spring Boot (backend) y Angular (frontend), usando MySQL como base de datos.

Modulos principales

  • Autenticacion de usuarios
  • Gestion de pacientes
  • Gestion de medicos y especialidades
  • Agenda y estados de citas (pendiente, confirmada, atendida, cancelada)
  • Dashboard con resumen general

Automatizacion CI/CD

Este proyecto usa GitHub Actions para automatizar:

  • Validacion de la estructura del repositorio
  • Compilacion del backend con Maven
  • Compilacion del frontend con npm/Angular
  • Build completo del sistema
  • Despliegue de esta pagina de documentacion en GitHub Pages

El despliegue del sistema completo (backend + frontend + MySQL) se realiza con docker compose up --build.
